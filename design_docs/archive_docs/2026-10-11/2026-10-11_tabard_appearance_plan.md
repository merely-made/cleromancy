# Shared application appearance

**Status (2026-10-11):** landed. CPU gates, final native acceptance and publication preparation complete; see the canonical receipt. Hocket was published first.

## Boundary and behavior

Cleromancy's native shell will compose Tabard's existing registry, choice store,
appearance resolver, and workshop over its ordinary consultation. Cambium owns
the title-bar slots, caption controls, retained input, layout, and paint. The
shared workshop native binding owns preview producers, text fields, export
effects, and dirty-close decisions. Cleromancy owns the application choice,
its presentation cascade, and whether an editor close also closes the window.

This work does not implement C1. The existing consultation worker, snapshot
store, replay validator, domain registration, admission, and personal-sync
consent keep their present authority and behavior. The divination mere plan
continues to own their migration and acceptance. Appearance cannot enqueue a
reading, reflection, chart calculation, graph mutation, or sync action.

The reusable consultation view receives host theme roles and gains no local
appearance picker. A separate native state wraps the consultation and its
appearance model. The native frame supplies an ornament, title, Appearance
action, and platform captions through Cambium's shared title bar. Selecting a
theme or mode persists the choice before publishing its resolved presentation.
Malformed choice files remain intact and block replacement. Unreadable theme
libraries remain visible and disable authoring until an explicit safe reload.

The current dark product colors remain the missing-preference default. An
explicit default action restores them. Canonical modes derive through Tinct
and Tabard; authored CSS remains exact and last in the application cascade.
The authoring sheet replaces that product cascade while the workshop is open,
so arbitrary application CSS cannot style the workshop controls. Saving a
definition updates the library, while Apply alone changes the application.
An applied snapshot stays active when its definition is saved under the same
identity, including after returning from the editor or reloading the library.

Application preferences use a host-local file under the existing data root.
The ordinary library is the shared Mere/Tabard library; an explicitly isolated
`CLEROMANCY_ROOT` uses a private library unless its path is overridden. Explicit
appearance and library environment overrides support acceptance profiles. The
workshop protects the entire application data directory from exports, including
missing future destinations, and also protects an overridden choice path.
Shared library generation and alias/collision protection remains the workshop's
responsibility. Export cancellation never saves or applies a definition.

## Phases and done-conditions

1. **Native composition and dependency identity.** Use one immutable Mere
   source, one Genet source, the existing Dramatis owner for optional Personae,
   and the maintained renderer's explicit root patches. Keep the portable
   acceptance package coherent. Done when metadata proves the complete source
   graph and the source adapter compiles without taking over migration APIs.
2. **Mounted appearance and ownership.** Exercise ordinary title-bar, theme,
   mode, edit, text, Save, Apply, Back, and dirty-close controls through the
   production retained host. Done when modes and exact authored CSS reach
   product paints; preferences and same-identity saves hold the correct applied
   snapshot; failed writes preserve bytes and presentation; exports cannot
   replace application truth; and reading drafts remain untouched.
3. **Native acceptance and integration.** After the parent explicitly releases
   the serialized GPU slot, run the ordinary LaunchServices host with private
   profiles. Done when wide and narrow layouts, four modes, authored Save/Apply,
   preview producers, close cancellation, and fresh reopen have actual receipt,
   presentation, capture, and pixel evidence. Keep rejected evidence. Fetch and
   reconcile origin before publication, and publish only after Hocket.
