# Cleromancy Sky

Turnstone's pure named-zone timeline and stable receipt implementation, now an embeddable library hosted with Turquet. Caller-owned observer, numerical controls, Earth-orientation source and ephemeris remain explicit. Named civil days retain 23/24/25-hour boundaries. Turnstone retains its pane, controls and navigation; Cleromancy retains interpretation and UTC/twilight policies.

Existing 0.13 V1 receipt bytes stay readable with their original engine identity. New calculations identify Turquet 0.17 at its imported source revision. Receipts are inspectable evidence, not a bit-for-bit replay promise across engine editions.

See `source-import.json` for the Turnstone donor revision and file blobs. Source is MPL-2.0; Turquet retains its own MIT/provenance and SOFA notices.
